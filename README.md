# PageSneak

> 一个「看起来在干活」的 Windows 桌面阅读器 —— 界面可伪装成代码编辑器、表格、购物页面或半透明悬浮条，读小说时不必担心被一眼看穿。

本仓库是 **PageSneak 的正式发行页**。可执行文件通过 [Releases](../../releases/latest) 分发，源码暂未公开。

## 下载

前往 **[最新版本 Releases](../../releases/latest)** 下载 `PageSneak-v1.0.0.exe`。

- 单文件绿色版，**免安装**，双击即用
- 系统要求：Windows 10 / 11（64 位）
- 体积约 49 MB，首次启动会自解压到 `%TEMP%`，约需 2–5 秒

## 使用

### 四种伪装方式

| 方式 | 外观 | 适合场景 |
|---|---|---|
| 编辑器 | 深色代码编辑器，带行号、语法高亮色块 | 最通用 |
| 表格 | 电子表格，带行号列、列标条、单元格网格 | 戴着「在做数据」的帽子 |
| 购物页 | 商城商品页，带深色导航条与搜索框 | 看起来像在比价、选品 |
| 悬浮条 | 半透明窄条，始终置顶、不进任务栏 | 挂在屏幕角落，随时瞥一眼 |

切换方式：**托盘图标右键 → 伪装方式**，或打开设置面板（默认停在「基本设置」）。

### 快捷操作

- **一键隐藏**（老板键）：默认 **Alt + 反引号键**（键盘左上角 `Esc` 下面那颗），可在设置里改
- 窗口拖动：伪装为编辑器 / 表格 / 购物页时，按住标题栏拖动
- 悬浮条：可拖动、可调透明度、始终置顶
- 关闭窗口 = 收进托盘（真正退出请用托盘菜单，或按 Ctrl+Q）

### 阅读进度会被记住

正文位置、字体、字号、行距、伪装方式、窗口位置都会自动保存，
下次打开接着上次的地方继续。配置文件位于：

```
%APPDATA%\PageSneak\settings.json
```

### 支持格式

`.txt`（UTF-8 / GBK 自动识别）与 `.epub`。

### 开机自启

在设置里开关。开启后会写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
值名为 `PageSneak`。程序每次启动会自检这条记录：**只在路径失效时修复，不会动你的开关状态**。

### 卸载

绿色单文件，删掉 exe 即可。若想彻底清理：

1. 设置里关掉开机自启
2. 删除 `%APPDATA%\PageSneak\` 目录

## 常见问题

**双击没反应？**
查看崩溃日志：`%TEMP%\pagesneak_crash.log`，里面有分阶段的导入记录与完整堆栈。

**想自检环境是否正常？**
命令行运行 `PageSneak-v1.0.0.exe --selftest`，会真跑一遍 txt / epub 解析并输出报告
（报告写入 `%TEMP%\pagesneak_selftest.txt`）。15 项全过即为正常。

**窗口跑到屏幕外找不到了？**
程序启动时会自检窗口可见性并尝试拉回；仍不行就删除 `%APPDATA%\PageSneak\settings.json`
（会重置设置与进度）。
